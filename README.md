# PVS Gold Smith

A simple, premium three-page brand and business information website for PVS Gold Smith, established since 1998 in R.S. Pura, Jammu.

## Pages

- `index.html` Home, brand introduction, craft categories, rate preview and store CTA
- `about.html` Story, values, hallmark and founder placeholder
- `contact.html` Store details, Instagram and directions

## Technology

HTML5, CSS3 and vanilla JavaScript. The supplied jewellery photography is used locally from the project root. `Logo.PNG` is the official logo and is referenced without modification.

## Customization

Replace the local JPGs with owned product photography while preserving filenames, add the official Google Maps place link in `contact.html`, and add store hours only when provided. The owner portrait area is intentionally a neutral placeholder.

## Run and deploy

Open `index.html` directly or serve the folder with any static server. Deploy to GitHub Pages, Netlify or Vercel static hosting.
